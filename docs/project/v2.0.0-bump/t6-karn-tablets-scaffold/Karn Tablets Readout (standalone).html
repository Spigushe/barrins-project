Karn Tablets Readout

What the metagame-clustering job actually computed: Duel Commander tournament decks (scraped into bs_*) grouped into archetypes by scikit-learn k-means, then pushed to barrins_api's kt_* tables. Every number below is read back out of those tables through the same /bff/tolaria-news routes the frontend will use.

Metagame now

Archetype share of the most recent clustering run for each window mode, largest first. Share is a cluster's deck count over the run total.

Across banlist periods

One clustering run per Duel Commander banlist period since mid-2024. Each panel tracks a single archetype's share of the metagame over those periods — a gap means the archetype had no cluster in that run. Archetype identity is carried across runs by commander, so a deck's 99 flexible cards drifting between periods doesn't fork it.

Rolling 30-day check

The other window mode, two runs a fortnight apart — a quick read on whether the picture is stable between a rolling window and a banlist-aligned one.
