# Release Retrospectives

After each release ships, this section records what the release actually
took: a timeline, the milestones delivered, the challenges that came up
(especially ones that repeated across independently-worked items — that
repetition is itself a signal worth acting on), key data, and any
Constitution amendments the release suggests. It's written the same way
[Operations](../operations/index.md) and [Roadmap](../roadmap.md) are:
honest about what went wrong, not just what shipped.

This is a different altitude from [Roadmap](../roadmap.md), which tracks
scope moving *into* and *out of* each release, and from the
[Decision Records](../architecture/decisions.md), which capture individual
architectural decisions regardless of which release they landed in. A
retrospective looks *back* at one release's execution specifically.
